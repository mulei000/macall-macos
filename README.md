macall 是一个开源（GPL-3.0）的 macOS **菜单栏「多合一」效率工具**。它把窗口管理、系统监控、剪贴板、音频、屏幕工具等能力装进一个菜单栏 App，按 `Feature` 模块化的方式增量扩展。

---

## 功能一览

### 系统监控
- 电池 / CPU / 内存 / 磁盘 / 网络 / 耗电 App 实时监控（全部用户态读取，**无需任何权限**）

### 窗口管理
- **窗口分屏**：半屏 / 三分之一 / 四等分，带竖向选择器
- **边缘吸附分屏**
- **跨屏移动**
- **隐藏窗口 / 一键显示桌面**
- **窗口置顶**（Always-on-Top）
- **窗口切换**：⌥Tab 类 AltTab 预览
- **场景布局**：保存 / 恢复整套窗口排布（临时场景 + 可命名预设）
- **Dock 反转**

### 剪贴板
- **剪贴板历史**：图文混排 / 文件类型识别 / 置顶 / 搜索
- **文本片段**（Snippets）
- **剪贴板 OCR**：识别剪贴板里图片中的文字并回写

### 音频
- **音量控制**：主音量状态栏 + 逐 App 音量 + 增益
- **输出设备切换**
- **输入设备切换**
- **麦克风静音**（默认 ⌃⌥J）
- **音频设备优先级**：自动路由
- **系统提示音输出设备**选择

### 屏幕 / 视觉
- **屏幕放大镜**（默认 ⌃⌥Z）
- **屏幕预览**（Preview）
- **颜色取色器**（默认 ⌃⌥C）
- **二维码生成**（默认 ⌃⌥Q）

### 电源 / 显示
- **电源动作**：锁屏 / 休眠 / 重启 / 关机 / 深色模式切换（部分走私有 API）
- **DDC 亮度调节**（默认 ⌃⌥, / ⌃⌥.）

### 触控板手势
- **边缘滑入调节**：从触控板左 / 右边缘滑入并上下拖动，调亮度 / 音量；调节过程中数值每跨约 2% 给一次「咔哒」逐级触觉反馈；灵敏度可在设置里自定义

### 工具箱
- 常驻状态栏图标，收纳小工具
- **键盘清洁模式**：锁定键盘 + 鼠标解锁 + 定时自动退出 + 自动熄屏

### 效率
- **快捷键速查**（默认 ⌃⌥H）：弹出浮层查看所有已启用快捷键

> 多数功能的默认快捷键是 **⌃⌥（Control + Option）+ 某键**，且**全部可在设置里修改**；不确定的组合直接按 ⌃⌥H 看速查面板。

## 架构

```
Sources/macall/
  Core/        Feature 协议 + 注册表、配置、权限、日志、版本
  Features/    各功能模块（每个遵守 Feature 协议）
  UI/          设置界面、状态栏弹窗、App 图标
Resources/     图标、entitlements、Info.plist
QuickActions/  （如有）服务类扩展
```

新增一个功能 = 新建一个遵守 `Feature` 的文件，并在 `AppDelegate` 的 `features` 数组里注册一行，其它代码基本无需改动。

## 安装

### 方式一：下载 DMG（推荐普通用户）
到 Releases 下载 `macall-0.5.0.dmg`，拖入「应用程序」即可。
> App 使用开发者证书签名（固定证书，TCC 权限跨版本保留）。若系统仍提示「无法验证开发者」，请在「系统设置 → 隐私与安全性」里手动允许。

### 方式二：从源码构建
只需命令行开发者工具（**无需完整 Xcode**）：

```bash
xcode-select --install            # 若尚未安装命令行工具
git clone https://github.com/mulei000/macall-macos.git
cd macall-macos
bash build.sh                     # 编译 + 组装 .app（默认不打包 dmg）
```

构建产物在 `build/macall.app`，可手动拖到 `/Applications`。
需要 DMG 安装包：`MAKE_DMG=1 bash build.sh`。

> **签名说明**：默认用名为 `macall Code Signing` 的固定证书签名（见 `build.sh` 与 `Resources/macall.entitlements`）。
> 若用自己的证书，请改 `build.sh` 里的证书标识；若完全不签名，依赖辅助功能 / 输入监控的功能在受限环境下可能受影响。

## 使用

1. 启动后菜单栏出现 macall 图标，点击展开仪表盘弹窗（实时监控 + 功能入口）。
2. 打开设置（状态栏图标菜单或对应快捷键），按模块开关功能、配置快捷键与参数。
3. 首次使用需要授权（在「系统设置 → 隐私与安全性」）：
   - **辅助功能**：全局快捷键、窗口操作、边缘吸附、Dock 扫描
   - **输入监控**：键盘 / 输入类功能
   - **屏幕录制**：需要读取屏幕像素的功能（放大镜 / 取色器 / 剪贴板 OCR 等）
   - **麦克风**：麦克风静音功能
4. 若某功能「点了没反应」，多半是对应的权限没开，或需要完全退出 App 再重开让权限生效。
